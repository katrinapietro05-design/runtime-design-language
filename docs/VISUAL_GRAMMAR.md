# Runtime Visual Grammar (Draft)

This document seeds the design-language target recorded as SOV-P-31. It is a specification scaffold; it does not replace the canonical symbol registry or declare unregistered marks canonical.

## Visual tokens

- **Role:** identify component or layer.
- **State:** show the current registered state.
- **Transition:** distinguish an event or change from a stable state.
- **Evidence:** label observed, synthetic, simulated, or empirical material.
- **Authority:** display the governing boundary and responsible source.

## Rules

1. Preserve canonical symbols and their registered meanings.
2. Keep state, transition, evidence, and authority visually distinct.
3. Make source, version, and validation status inspectable.
4. Use animation only when it communicates a defined transition.
5. Prefer accessible contrast, labels, and non-color cues.

## Dependencies

Symbol and Glyph Registry; UI/runtime systems; Runtime Visual Atlas.
